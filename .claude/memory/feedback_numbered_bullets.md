---
name: feedback_numbered_bullets
description: Always use numbered bullets when listing options or items for the user to choose from or refer to
type: feedback
---

Always use numbered bullets when presenting lists, options, or items the user might want to refer back to.

**Why:** User's system instructions explicitly require this so they can refer to items by number in follow-up messages.

**How to apply:** Any time the response contains a list of more than one item - options, recommendations, steps, caveats - use numbered bullets (1, 2, 3...) instead of dashes or prose enumeration.
