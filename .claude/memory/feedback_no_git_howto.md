Don't instruct the user on how to carry out operations in git, for example
how to stage individual hunks. Naming a git command is fine, as is pointing
out the state of the repository or the consequences an operation will have.

**Why:** The user is experienced with git and finds such instructions
unnecessary.

**How to apply:** When git work is needed, state what has to happen and
leave the procedure to the user.
