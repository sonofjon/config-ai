---
name: feedback_auto_update_docs
description: Automatically update AGENTS.md and README.md when making code changes
type: feedback
---

Always update AGENTS.md and README.md files automatically when code changes affect them, without being asked.

**Why:** The user expects documentation to stay in sync with code changes as part of the implementation, not as a separate step.

**How to apply:** When creating, moving, renaming, or restructuring modules, classes, or test files, include the corresponding AGENTS.md and README.md updates in the same change.
